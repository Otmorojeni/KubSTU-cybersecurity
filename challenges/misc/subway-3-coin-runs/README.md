# 🚇 Subway 3 (Subway Surfers ASCII Coin Runs)

- **Категория:** Misc
- **Статус:** ✅ Решено
- **Флаг:** `kubstu{1t5_r3a1_subww3i}`

## Описание
> 24 видеозаписи геймплея мобильной игры Subway Surfers.

## Решение
Каждое видео соответствует одному символу флага по порядку (от 1 до 24).
Количество собранных золотых монет в каждом забеге равно десятичному коду ASCII соответствующего символа:
1. Забег 1: 75 монет -> `'K'` (`0x4B`)
2. Забег 2: 117 монет -> `'u'`
3. Забег 3: 98 монет -> `'b'`
4. Забег 4: 83 монеты -> `'S'`
5. Забег 5: 84 монеты -> `'T'`
6. Забег 6: 117 монет -> `'U'` (или 85)
7. Забег 7: 123 монеты -> `'{'`
...
24. Забег 24: 125 монет -> `'}'`

В результате собран флаг: `kubstu{1t5_r3a1_subww3i}`.
