# 🦫 Капибара и сертификат (AES Is Secure, Right)

- **Категория:** Crypto
- **Статус:** ✅ Решено
- **Флаг:** `KubSTU{c3rt1f1c4t3_r3v0k3d}`

## Описание
> Капибара КубГТУ закрыла компьютерный класс и машет сертификатом по ИБ: мол, всё зашифровано правильным алгоритмом, не подкопаешься. Алгоритм и правда хорош. А вот всё, что вокруг него, — уже вопрос. Исходники её поделки нашлись на кафедральном компьютере. Докажите капибаре, что сертификат ей выдали рано.

## Решение
Сам симметричный шифр AES криптографически стоек, однако в реализации протокола проверки сертификатов и управления ключами присутствовала логическая ошибка валидации статуса отзыва сертификата (Certificate Revocation / CRL / OCSP), позволяющая восстановить секретный ключ шифрования.
