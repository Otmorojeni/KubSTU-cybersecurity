## Описание
> Поток, кривизна, эволюция формы. Приложен код, который «примерно» показывает, как из каскада рождается кривая, и её изображение — правда, слегка повреждённое. Остальное придётся восстановить самостоятельно.

## Решение
Задача посвящена геометрической эволюции кривых и доказательству гипотезы Пуанкаре Григорием Перельманом. Написан скрипт обратной реконструкции параметров кривой из каскада геометрических деформаций, восстановивший полный текст флага.
