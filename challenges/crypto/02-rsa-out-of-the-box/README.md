## Решение
В файле `output.txt` предоставлены параметры шифрования RSA (модуль $n$, открытая экспонента $e$ и шифротекст $c$).
Использованы стандартные уязвимости генерации параметров (факторизация модуля $n$ через Fermat factorization / Wiener attack / Pollard p-1 / factorise DB):
1. Нахождение простых делителей $p$ и $q$, таких что $n = p 	imes q$.
2. Вычисление функции Эйлера $\phi(n) = (p-1)(q-1)$.
3. Вычисление закрытого ключа $d = e^{-1} \pmod{\phi(n)}$.
4. Расшифровка открытого текста $m = c^d \pmod n$.
5. Преобразование числа $m$ в строку байтов дает флаг.
