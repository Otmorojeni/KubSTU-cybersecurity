# 🔢 Decimal Stream (Поток чисел)

- **Категория:** Crypto / Misc
- **Статус:** ✅ Решено
- **Флаг:** `KubSTU{d3c1m4l_15_my_l4n6u4g3}`

## Описание
> 75 117 98 83 84 85 123 100 51 99 49 109 52 108 95 49 53 95 109 121 95 108 52 110 54 117 52 103 51 125
> Нам достался только поток чисел. Никаких букв — одни числа через пробел. Но компьютер ведь тоже хранит текст числами. Переведи обратно.

## Решение
Каждое число представляет собой десятичный ASCII-код соответствующего символа:
- `75` -> `'K'`
- `117` -> `'u'`
- `98` -> `'b'`
- `83` -> `'S'`
- `84` -> `'T'`
- `85` -> `'U'`
- `123` -> `'{'`

Пайплайн решения на Python:
```python
nums = "75 117 98 83 84 85 123 100 51 99 49 109 52 108 95 49 53 95 109 121 95 108 52 110 54 117 52 103 51 125"
flag = "".join(chr(int(x)) for x in nums.split())
print(flag)
# KubSTU{d3c1m4l_15_my_l4n6u4g3}
```
