# 🌫️ The Deterministic Fog (Постквантовая LWE криптосистема)

- **Категория:** Crypto / Post-Quantum
- **Статус:** ✅ Решено

## Описание
> В КубГТУ собрали экспериментальную постквантовую криптосистему на Learning With Errors, а шум для неё доверили собственному детерминированному генератору: «хаос от случайности никто не отличит». Начальное состояние спрятали, но сам прибор для диагностики логирует короткий калибровочный след источника шума — «это же просто пара служебных отсчётов, ничего секретного». Капибара из соседней лаборатории посмотрела в код и не согласилась. Вам достались реализация и данные одного сеанса. Восстановите флаг.

## Решение
Схема Learning With Errors (LWE) основана на трудности поиска секрета при добавлении малого случайного шума.
В данной задаче источник шума был псевдослучайным и детерминированным. По предоставленным в логе калибровочным отсчетам было полностью реконструировано внутреннее состояние PRNG, сгенерированы точные значения шумовых векторов для раунда шифрования и вычтены из шифротекста, что свело задачу к тривиальной линейной системе над конечным полем.
