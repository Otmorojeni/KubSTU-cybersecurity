# 🕵️ Зашифрованные передачи L (Меркл-Хеллман / LLL Lattice Attack)

## Описание
> Перехвачены зашифрованные передачи L. Открытый ключ один, сообщение разбито на блоки. Как L превращает блок в одно число — видно из данных. Обратно — ваша задача.

## Решение
Шифрование представляет собой разновидность рюкзачной криптосистемы Меркла-Хеллмана:
каждый блок $M = (b_0, b_1, \dots, b_{n-1}) \in \{0, 1\}^n$ преобразуется в число:
$$C = \sum_{i=0}^{n-1} b_i a_i$$
где $A = \{a_0, \dots, a_{n-1}\}$ — открытый ключ рюкзака.
Для восстановления исходного битового вектора была построена матрица решётки Клоза/Бабая размерности $(n+1) 	imes (n+1)$ и применён алгоритм редукции базиса LLL (Lenstra–Lenstra–Lovász). Редуцированный базис содержит вектор с коэффициентами $\{0, 1\}$, соответствующими открытому тексту.
