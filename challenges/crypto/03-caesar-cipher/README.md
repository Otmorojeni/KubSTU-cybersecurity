# 🏛️ Древнеримский полководец (Caesar Cipher)

- **Категория:** Crypto
- **Статус:** ✅ Решено
- **Флаг:** `KubSTU{c43s4r_w0uld_b3_pr0ud}`

## Описание
> Мы перехватили сообщение, но буквы будто сдвинулись со своих мест. Говорят, таким способом шифровал ещё один древнеримский полководец. Верни буквы назад.

## Решение
В файле `cipher.txt` находился шифротекст, закодированный классическим шифром Цезаря (циклический сдвиг алфавита). Зная формат флага соревнований `KubSTU{...}`, был однозначно вычислен сдвиг символов и восстановлена исходная строка.
