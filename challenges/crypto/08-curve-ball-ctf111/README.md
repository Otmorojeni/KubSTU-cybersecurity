## Описание
> Нам достался зашифрованный артефакт сборки и два открытых ключа. Один из них выглядит до боли знакомо — и этим всё сказано. Восстановите исходник, а потом загляните глубже. Там, где кажется, что вы уже нашли ответ, вы его ещё не нашли.

## Решение
Криптосистема на базе эллиптической кривой $E(\mathbb{F}_p)$.
1. Вычисление порядка группы кривой $\#E(\mathbb{F}_p)$ показало, что порядок является $B$-гладким (раскладывается на произведение небольших простых множителей).
2. С помощью системы компьютерной алгебры PARI/GP (`ellorder`, `elllog`) был применён алгоритм Полига-Хеллмана (Pohlig-Hellman) и метод «шаг младенца, шаг великана» (BSGS) для решения задачи дискретного логарифма по каждому малому модулю.
3. По китайской теореме об остатках (CRT) был вычислен секретный ключ и расшифрован шифротекст.
