# 🗺️ Каршеринг в центре (Краснодар OSINT / Панорамы)

- **Категория:** OSINT / Geolocation
- **Статус:** ⏳ В процессе

## Описание
> Однажды после пар взяли с друзьями каршеринг и покатались по центру. Машину бросили где-то в тени деревьев и сфоткались на память. Пока искали следующую, начисто забыли, где оставили эту. Помоги вспомнить: где мы её припарковали? Достаточно будет координат с 4-мя знаками после запятой.
> Формат флага: KubSTU{lat_lon}

## Исследование
1. По архитектурным деталям на заднем плане (кирпичная кладка, арочные ниши, озеленение) был локализован исторический центр Краснодара (район улиц Кирова, Комсомольская, Октябрьская, Мира, Красная).
2. Написаны скрипты выгрузки панорам Яндекс.Карт по координатам и углам обзора для автоматического сопоставления.
