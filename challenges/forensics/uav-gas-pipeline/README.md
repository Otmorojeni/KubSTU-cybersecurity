# 🛩️ Падение БПЛА на газопроводе

- **Категория:** Forensics / Hardware
- **Статус:** ⏳ В процессе (на этапе дешифровки контейнера)

## Описание
> С 12 по 16 сентября БПЛА самолётного типа каждый день снимал 62-километровый коридор газопровода в Краснодарском крае. Пятый вылет закончился падением. Оператор в тот же вечер нашёл обломки, снял карту памяти и подал заявление в страховую...

## Анализ
1. В файловой системе обнаружен текстовый файл `NOTES.TXT` с фальшивым флагом: `KubSTU{n0t_th3_r34l_0n3_k33p_d1gg1ng}`.
2. В неразмеченном пространстве карты памяти (кластер 17207) обнаружен второй decoy-флаг: `KubSTU{gps_c00rds_4r3_n0t_3n0ugh}`.
3. Истинный флаг зашит внутри 672-байтного бинарного контейнера (OpenSSL AES-256-CBC `Salted__`). Для расшифровки необходим точный ключ из параметров телеметрии полета APM.
