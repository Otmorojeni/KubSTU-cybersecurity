# 🛡️ ООО «ГидроТек» (Cybercamp DFIR Investigation)

- **Категория:** Forensics / Incident Response
- **Статус:** ✅ Расследование завершено (10/10 ответов)

## Легенда
ООО «ГидроТек» — компания в области промышленного насосного оборудования. Утром хосты домена были зашифрованы программой-вымогателем Medusa Locker. Проведено детальное расследование цепочки компрометации:
1. **Первоначальный доступ:** компрометация внутреннего портала Joomla через вебшелл в шаблоне CMS (`atomic`, обращения с внешнего IP).
2. **Закрепление:** создание задачи планировщика `schtasks` с бинарником и параметром `-s <hex>`.
3. **Повышение привилегий (LPE):** скрытая директория в `/dev/shm` на шлюзе `gw-hydro`.
4. **Латеральное движение и отключение защиты:** изменение групповой политики Active Directory (GPO) для отключения Windows Defender на всех машинах.
5. **Анализ шифровальщика:** PowerShell ScriptBlock Logging (Event ID 4104), мьютекс и логика блочного шифрования файлов.
