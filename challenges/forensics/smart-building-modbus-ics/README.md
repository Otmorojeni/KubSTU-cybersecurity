# 🏭 Лаборатория «Умного здания» (Modbus TCP ICS Traffic)

- **Категория:** Forensics
- **Статус:** ✅ Решено
- **Флаг:** `KubSTU{modbus_echoes_keep_the_secret}`

## Описание
> После ночного технического обслуживания лаборатории «умного здания» пропал журнал калибровки контроллера. Сетевой дамп содержит данные мониторинга, обновления, управления оборудованием и крупномасштабного резервного копирования. Аналитик уверен, что журнал был передан по одному из служебных каналов.

## Решение
В сетевом дампе `echoes_of_the_plc.pcap`:
1. Отфильтрован высоконагруженный фоновый трафик резервного копирования (HTTP, SMB).
2. Выделен промышленный протокол управления контроллерами Modbus TCP (порт 502).
3. Проанализированы функции чтения/записи holding-регистров (Function Code 3 и 16).
4. В полезной нагрузке эхо-ответов ПЛК обнаружена скрытая передача байтов флага.
