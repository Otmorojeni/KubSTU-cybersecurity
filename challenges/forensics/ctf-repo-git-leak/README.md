# 🐙 Git Leaks (Утечка служебных ключей)

- **Категория:** Forensics
- **Статус:** ✅ Решено

## Описание
> Служба безопасности обнаружила подозрительную активность: из производственной среды произошла утечка служебных ключей. Разработчик утверждает, что сразу заметил ошибку и откатил изменения.

## Решение
1. Исследование локальной структуры git-репозитория (`git reflog`, `git log --all --reflog`, `git fsck --lost-found`).
2. Извлечение удаленных/висячих коммитов и объектов (`git show <dangling_commit>`).
3. Обнаружение скомпрометированных токенов и ключей доступа.

> **Примечание:** Внутренний каталог `.git` задания сохранён под именем `ctf_repo/ctf_repo/.git_challenge` (во избежание конфликта вложенных репозиториев git). Для исследования переименуйте его обратно в `.git`:
> ```bash
> mv ctf_repo/ctf_repo/.git_challenge ctf_repo/ctf_repo/.git
> cd ctf_repo/ctf_repo && git log --all --reflog
> ```
