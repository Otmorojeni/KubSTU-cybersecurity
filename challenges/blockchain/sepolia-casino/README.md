# 🎲 Казино на смарт-контрактах в Sepolia (Bad Randomness)

- **Категория:** Blockchain / Web3
- **Статус:** ✅ Решено
- **Флаг:** `KubSTU{bad_randomness_same_tx}`

## Описание
> В Сеполии есть надежное казино на смарт-контрактах. Оно прячет флаг за игрой «Угадай число» и клянется, что его генератор случайных чисел честный, свежий и практически волшебный. Докажите контракту, что его удача предсказуема, и получите флаг.

## Уязвимость и Решение
Классическая уязвимость генерации псевдослучайных чисел в блокчейне Ethereum (SWC-120: Weak Sources of Randomness from Chain Attributes).
Смарт-контракт вычислял случайное число на основе текущих атрибутов блока:
```solidity
uint256 random = uint256(keccak256(abi.encodePacked(block.timestamp, block.prevrandao, msg.sender))) % MAX;
```
Для эксплуатации был развернут контракт-эксплойт, вызывающий метод казино в той же транзакции:
1. Эксплойт вычисляет точное значение `random` по тем же параметрам текущего блока.
2. Передает предсказанное число в качестве ставки.
3. Забирает победу и извлекает флаг: `KubSTU{bad_randomness_same_tx}`.
