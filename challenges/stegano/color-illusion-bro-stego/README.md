# 🎨 [STEGO] Color Illusion (На заводе стих шум / DCT Steganography)

- **Категория:** Hardware / Steganography (147 pts)

## Описание
> На заводе стих шум, но кое-что всё ещё работает на своих частотах. Найдите спрятанный флаг.

## Решение
Стеганографический контейнер `bro_stego_with_hint.png` скрывал внедренные биты в частотных коэффициентах двумерного дискретного косинусного преобразования (2D-DCT) блоков $8 	imes 8$:
1. Преобразование цветового пространства изображения в YUV.
2. Разбиение яркостного канала Y на независимые блоки $8 	imes 8$.
3. Поиск аномальных частотных всплесков (frequency spikes) на средних и высоких частотах.
4. Знаки модификаций коэффициентов кодировали битовую последовательность данных.
