# 📺 Madkid (SCTV Audio Decode)

- **Категория:** Steganography / Radio
- **Статус:** ✅ Решено

## Описание
Аудиодорожка с модуляцией SSTV (Slow-Scan Television, любительское аналоговое телевидение).
Написан скрипт `sstv_decoder.py`, декодирующий частотно-модулированный сигнал звукового диапазона 1500–2300 Гц в растровое изображение.
