# ⚙️ Прошивка RISC (fw.bin)

- **Категория:** Reverse / Firmware
- **Статус:** ✅ Решено
- **Флаг:** `KubSTU{tr4ps_4r3_th3_r34l_c0ntr0l_fl0w}`

## Описание
> Вычислительная система с сокращённым набором команд. Вспомните лекции по компьютерному оборудованию.

## Решение
1. Архитектурный анализ дампа прошивки `fw.bin` выявил опкоды учебного RISC-процессора (архитектура LC-3 / Little Computer 3).
2. Написан дизассемблер и эмулятор на Python (`solve_fw.py`).
3. Разобрана обработка системных вызовов через прерывания (инструкции `TRAP`).
4. Восстановлен алгоритм расшифровки строки валидации, приведший к флагу.
