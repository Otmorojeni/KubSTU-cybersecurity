# ⏳ Chronos (Mach-O Easter Eggs & Section Encryption)

- **Категория:** Reverse
- **Статус:** ✅ Решено
- **Флаг:** `KubSTU{k3y3d_by_1ts_0wn___t3xt_s3ct10n}`

## Описание
> Мы сделали здесь небольшую программу. Разработчик оставил множество пасхалок.

## Решение
1. Бинарный файл представляет собой 64-битный исполняемый файл формата Mach-O (macOS x86_64).
2. Анализ секций `__TEXT` и `__DATA` показал наличие кастомных зашифрованных блоков `__d5` и `__d7`.
3. Алгоритм дешифрования использует хеш контрольной суммы секции исполняемого кода `__TEXT,__text` в качестве ключа (self-keyed binary).
4. Восстановлена функция расшифровки и извлечен основной флаг соревнования.
